VelaPlayer · 支持

最后更新：2026 年 11 月 10 日 · 适用版本 2.1.0 · iOS 16.0 及以上

VelaPlayer 是一款本地视频播放器：不注册、不联网、不提供任何片源。 你播放的视频全部由自己通过 Wi-Fi 网页、AirDrop 或系统「文件」App 导入。

2.1.0 新增：继续观看、字幕工作台、iPad 分栏导航、首启导入引导。

常见问题

  • 哪些格式能播？内置 VLC 解码引擎，支持 MKV / AVI / RMVB / FLV / TS / M2TS / WEBM / HEVC 及常规 MP4 / MOV / M4V。
  • 字幕怎么加载？把与视频同名的 .srt / .ass / .ssa / .vtt 放在同一目录即可自动匹配，支持 UTF-8 与 GBK 编码。
  • 字幕和画面不同步？播放页点顶部「滑块」图标打开字幕工作台，用 -5s ~ +5s 的滑块或「字幕提前 / 延后 0.5s」逐 0.1 秒校准，还能改字号与三种字幕样式。开启「增强字幕渲染」后由 VelaPlayer 自行绘制字幕（当前进度会自动保留），关闭时使用 VLC 原生渲染以保留 ASS 特效。
  • 怎么接着上次看？播放进度会自动记在本机，回到文件库顶部的「继续观看」点一下即可断点续播；看到 95% 以上的片会自动从列表移除。设置页可一键清除全部观看记录。
  • iPad 上有什么不同？平板使用左侧边栏分栏导航，可直接跳到资料库、私密文件夹、Wi-Fi 传输与文件导入，并展示本机视频数量、占用空间和当前解码引擎。
  • Wi-Fi 上传打不开？请保持 App 在前台、手机与电脑在同一 Wi-Fi，并在系统「设置 → 隐私与安全性 → 本地网络」中允许 VelaPlayer；权限变更后需彻底退出 App 重开。
  • 音量键没反应？播放页的竖向滑动与手机音量键都调节系统音量，请确保设备未静音。
  • 私密文件夹安全吗？它是 App 内的 Face ID 访问门禁，文件本身不额外加密；请勿用它存放需要磁盘级加密保护的内容。详见隐私政策。
  • 旧版本加密过的视频？首次启动会在后台把旧版加密容器还原为普通文件；如有个别文件未能还原，原始容器会保留在设备上，可联系我们协助处理。
